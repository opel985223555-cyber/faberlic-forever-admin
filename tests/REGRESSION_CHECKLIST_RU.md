# Регрессионная проверка Faberlic Forever

После любой правки одного блока сначала выполните:
`python tests/check_locked_files.py --allow app/src/main/assets/www/modules/<разрешенный_файл>`

Проверки после запуска приложения:

- [ ] Новая 6,3-секундная заставка запускается один раз и завершается, затем главная
- [ ] Нет старой 9,08-секундной анимации и дублирующей системной иконки
- [ ] Главная: баннер, свайп, поиск, видео, переходы
- [ ] «Обучение для команды» отсутствует в заголовке главной
- [ ] Категории: «Мотивация» отсутствует, существующие категории работают
- [ ] Вводного текста «Всё обучение разложено...» нет во всех трёх языках
- [ ] «Соцсети и продвижение»: 5 тематических подразделов
- [ ] «Обучение по статусам»: 3, 6, 9, 12, 15, 19, 23 процента
- [ ] Внутри новой папки открывается список уроков или корректная пустая страница
- [ ] Кнопка назад возвращает из урока/подпапки на уровень выше
- [ ] Эфиры: сохранены существующие 3 тестовых элемента
- [ ] Нет вступления «Расписание живого обучения...» на RU/TJ/UZ
- [ ] Материалы: сохранены существующие 3 тестовых элемента
- [ ] Подпись «Памятки, инструкции, презентации и чек-листы.» сохранена
- [ ] Избранное: сохранение и удаление работают
- [ ] RU / TJ / UZ: корректный перевод всех новых папок
- [ ] Фиксированное верхнее и нижнее меню, прокрутка центральной области
- [ ] Android 12+: перед 3D-анимацией не появляется старая системная иконка
- [ ] Функциональные тесты в реальном Android WebView после сборки APK

Перед изменением любого общего файла (`core/`, `styles.css`, `data.js`, `index.html`) требуется отдельное согласование.
