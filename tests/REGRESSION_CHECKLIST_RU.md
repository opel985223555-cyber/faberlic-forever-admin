# Проверка CMS-08 перед использованием

## Автоматизированные проверки (локальные)
- `python tests/test_admin_browser.py` — настоящий интерфейс Chromium, Firebase заменён локальным адаптером. Не используется интернет и не затрагиваются рабочие данные.
- `python tests/test_youtube_only_policy.py` — нет собственных обложек.
- `python tests/test_youtube_cover_preview.py` — обложки берутся с YouTube.
- `python tests/verify_module_lock.py` — проверка контрольных сумм утверждённых блоков.
- `node --check` для каждого JS-файла.

## Обязательные проверки после GitHub + Firebase
- [ ] Действующая учётная запись Firebase Authentication входит в CMS-08.
- [ ] Чужая/неактивная учётная запись не может управлять уроками.
- [ ] Обновлённые Firestore Security Rules опубликованы в Firebase Console.
- [ ] «Опубликовать структуру» выполняется один раз, без потери старых ID и видео.
- [ ] Существующая запись «Реклама» остаётся на месте.
- [ ] Новая категория и подраздел сохраняются после повторного входа.
- [ ] RU/TJ/UZ названия и описания корректно отражаются в Android после обновления клиента.
- [ ] «Скоро» и «Скрыт» работают, пустая категория не открывается в Android.
- [ ] Скрытую категорию можно выбрать в форме редактирования уже привязанного к ней урока.
- [ ] Новый урок добавляется в конец внутри выбранной категории и языка.
- [ ] Перестановка ↑/↓ сохраняется после перезагрузки сайта и видна в Android.
- [ ] Черновик не показывается в Android, публикация показывается.
- [ ] Обложка с YouTube видна в списке и в мобильном приложении, своих фото не требуется.
- [ ] Нет регрессии входа, категорий, плеера YouTube, полноэкранного просмотра и сердечка на Android.
