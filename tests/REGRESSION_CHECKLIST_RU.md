# Проверки Faberlic Forever Admin 0.3

## Автоматизированная локальная проверка
- [ ] Без Firebase-конфигурации виден только вход. Нет демонстрационного входа.
- [ ] В интерфейсе и активном JS нет тестовой авторизации и хранения уроков в localStorage.
- [ ] Модульные файлы проходят SHA-256 контроль.
- [ ] Отображение логотипа и фирменных цветов сохранено.

## После подключения настоящего Firebase (обязательно перед публикацией)
- [ ] Вход работает только по email и паролю Firebase Authentication.
- [ ] Только пользователь с `admins/{uid}` и `active=true` может управлять уроками.
- [ ] Без входа недоступны черновики и запись, редактирование, удаление уроков.
- [ ] Данные сохраняются в Firestore и видны после повторного входа с другого компьютера.
- [ ] YouTube-ссылки `youtube.com`, `youtu.be`, Shorts принимаются; поддельные домены блокируются.
- [ ] 9 категорий, 5 тем соцсетей, 7 статусов (3/6/9/12/15/19/23%).
- [ ] RU/TJ/UZ, 9:16/16:9, черновик и публикация.
- [ ] Редактирование, удаление, фильтры, поиск, счётчики.
- [ ] Переходы между всеми семью модулями.
- [ ] Уроки Android-приложения пока не меняются: интеграция Android отдельно.
