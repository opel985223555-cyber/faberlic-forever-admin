## Схема данных и правила

Существующая коллекция materials сохранена. Старые документы имеют прежние поля title/url/description/type/language/status/revision/createdAt/updatedAt и продолжают работать отдельно.

Новые materials schemaVersion=2: прежние строковые title/description/url для совместимости; titleTranslations/descriptionTranslations (ru/tj/uz), categoryId, country all/tj/ru/uz, provider google_drive/yandex_disk, sourceUrl, previewUrl, fileType, order, status, verifiedMime/verifiedName/verifiedSize и ревизии/времена. Старые записи массово не преобразуются. verified-поля — проверка админского интерфейса; привилегированный администратор технически может подделать метаданные, поэтому приложение перед открытием заново читает опубликованный документ с сервера, проверяет категорию, API и фактическую сигнатуру полученного файла.

Новая materialCategories: name/description карты ru/tj/uz, icon, order, status published/draft/hidden, revision, documentCount, membershipRevision, lastMaterialId, createdAt/updatedAt. Это отдельный каталог материалов, существующая видео-таксономия не меняется. Создание/перенос/удаление V2 документа связано атомарным изменением счётчиков с доказательством членства через getAfter в правилах. Удалить непустую категорию нельзя. Метаданные и порядок меняются с проверкой revision. Файлы на дисках не удаляются автоматически.

lessons: добавлены необязательные iconMode auto/manual и iconId. Старые уроки без них используют локальный подбор темы с fallback. orientation/aspectRatio и ранее реализованный адаптивный плеер сохранены. Новых составных индексов нет; запросы status-only. Полный текст правил и diff приложены отдельно, ничего не развёрнуто.
