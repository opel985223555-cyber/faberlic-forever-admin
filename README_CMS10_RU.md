# Faberlic Forever Android — CMS-10: материалы, эфиры, экран видео

Исходная утверждённая база: **CMS07_HEART_TOP_RIGHT**; изменены только отдельно запрошенные функции. Android `versionCode=9`, `versionName=0.9.8-content-player`.

## Видео

- «Новичку · RU» выровнено по левому краю области плеера и опущено немного ниже.
- Справа **под плеером**, а не поверх видео, размещена кнопка «На весь экран». Она запрашивает fullscreen у WebView; в полном экране есть `✕`, а штатная кнопка Android «Назад» сначала закрывает fullscreen, не закрывая сам урок.
- Кнопки и стрелки **внутри YouTube Shorts** остаются под контролем YouTube, их нельзя безопасно передвинуть CSS нашего приложения. Наличие или отсутствие внутренней кнопки YouTube зависит от плеера.
- Heart справа в шапке урока сохранён; у эфира он скрывается, поскольку эфиры пока не имеют избранного.

## Материалы и эфиры

- Новые независимые модули читают `materials` и `liveStreams` через отдельные подписки Firebase Firestore в `PublishedLessonsBridge.java`, **только `status == 'published'`**.
- Черновики не показываются. Язык RU/TJ/UZ учитывается. В пустом разделе отображается сообщение, а не тестовые данные.
- Материалы открываются по HTTPS-ссылке во внешнем браузере через Android Intent; WebView приложения не переходит на чужой сайт.
- Эфиры с YouTube ID открываются во встроенном проигрывателе. Состояния анонс/эфир/запись устанавливаются администратором вручную.

## Не менялось

Заставка, главный экран, категории, нижняя навигация, Firebase-загрузка обычных уроков, фирменные цвета, RU/TJ/UZ интерфейс и избранное. Изменён только необходимый слой перехода к внешним HTTPS-материалам, без изменений поведения остальных экранов.

## Непроверенное

- APK здесь не собран: нет настроенного Android SDK.
- `requestFullscreen()` и закрытие по `✕` нужно проверить на настоящем WebView, особенно для Shorts. Если WebView не поддерживает внешнюю fullscreen-кнопку, работает только встроенный вариант YouTube.
- Подключение к реальному Firebase возможно только после публикации корректных Security Rules для новых коллекций.
