# Android CMS-12 — скрытие и техническое обслуживание категорий

Это обновление исходного Android-проекта из Faberlic_Forever_Android_CMS10_CONTENT_FULLSCREEN (1).zip. Работает с кнопками админки CMS-12. Готовый APK не входит в архив.

## Использование

В админке CMS-12 откройте «Категории»:
- «Скрыть»: категория и её подразделы исчезают из списка приложения, а их видео — с главной и из отображаемого избранного.
- «Закрыть»: категория остаётся видимой с надписью «Закрыто на техническое обслуживание», вход заблокирован. Для TJ/UZ показывается перевод.
- «Открыть»: ограничение категории снимается. Видео и сохранённые отметки избранного восстанавливаются из существующих данных. Если родитель остаётся закрытым/скрытым, потомок остаётся недоступным. Если потомок закрыт отдельно, открытие родителя его не открывает.

При получении нового статуса из Firebase уже открытый закрываемый раздел возвращается к списку категорий, а его открытый плеер останавливается. Новые статусы приходят по существующей подписке Firestore без повторной публикации APK для каждого переключения. Для получения изменения нужен интернет и доставка события Firebase; офлайн-клиент не получает новые статусы мгновенно.

## Установка

1. Используйте уже подготовленную веб-админку CMS-12 с кнопками «Скрыть», «Закрыть», «Открыть». Если установлена CMS-11, сначала примените админский CMS12_UPDATE_FROM_CMS11.zip и обновите функцию cms11Catalog по инструкции админки. Новые Firestore Rules поверх CMS-11 для этого изменения не нужны.
2. Android_FULL.zip содержит весь проект. Android_CHANGED_FILES.zip содержит только изменённые и добавленные файлы для наложения на переданный Android CMS-10; распакуйте в корень Android-проекта, сохранив пути.
3. Откройте корневую папку проекта в Android Studio, выполните Gradle Sync и соберите APK обычным для вашего проекта способом. Зависимости и версии плагинов из исходного проекта сохранены. В комплекте исходного проекта нет Gradle wrapper; используется ваша существующая конфигурация Android Studio/Gradle.
4. Для обновления приложения без смены package используйте прежний ключ подписи. applicationId остаётся tj.faberlic.forever; версия увеличена с versionCode 9 до 12, versionName 0.9.12-category-access.
5. Установите собранную версию на телефон. Одна замена файлов на хостинге НЕ обновляет уже установленный APK.
6. Проверьте на тестовой категории: скрыть → исчезла; закрыть → видна надпись, вход закрыт; открыть → доступ вернулся. Видео специально удалять не нужно.

## Изменения

- Новый core/category-availability.js — та же модель наследования доступности, что в админке CMS-12 (отличается только глобальное имя модуля).
- modules/categories-cms.js — локализованная надпись обслуживания, наследование статусов, защита навигации, применение пустого каталога, проверка циклов и обновление открытого раздела.
- modules/firebase-lessons.js — единая проверка обычных и старых group/topic привязок; скрытие уроков на главной и в избранном; обновление фильтров; остановка закрытого видео.
- modules/lesson.js — дополнительная проверка перед открытием видео.
- modules/categories.css — только текст обслуживания внутри прежней карточки.
- index.html — подключение нового модуля.
- app/build.gradle — только номер версии.

Нативные Java-файлы, google-services.json, AndroidManifest, исходный YouTube-плеер, заставка, базовый дизайн, live.js/materials.js, логика авторизации и функции эфиров/материалов сохранены побайтно. Видео и документы в Firebase не изменялись. Статусы уроков не переписываются. Скрытие управляет интерфейсом, но не меняет существующие правила публичного чтения опубликованного видео по прямому ID.

## Проверки

Выполнены 14/14 браузерных проверок полного интерфейса приложения в Edge на ширине 390 px с имитацией Java-моста. Внешние запросы блокировались. Проверены RU/TJ/UZ, наследование статусов, скрытие главной/баннеров/избранного, сохранение отметок избранного, возврат после открытия, остановка плеера, закрытые дочерние категории, старые привязки topic, обычный «Скоро», пустой и некорректный каталог, все пять вкладок. Результаты: tests/CMS12_ANDROID_BROWSER_RESULTS.json.

Также выполнены tests_cms10.cjs, tests/test_player153_source.py, контроль замороженных файлов с разрешёнными изменениями и синтаксис всех JS/CJS. Сопоставлена логика доступности с админкой CMS-12; проверена целостность ZIP и неизменность остальных файлов.

Запуск новых тестов (нужен Node.js, установленный playwright и Edge в Windows; для другого браузера FF_BROWSER_PATH):

   node tests/test_cms12_availability.cjs
   node tests_cms10.cjs
   python tests/test_player153_source.py

Сборка APK, запуск на Android-устройстве, реальное подключение к Firebase и реальный YouTube playback в этом прогоне НЕ выполнялись. Старый Python-тест визуальной проверки плеера не запущен: отсутствует Python playwright; исходный плеер и нативные файлы проверены на неизменность. Браузерный тест не является эмулятором Android.

Ничего не публиковалось в Firebase/GitHub, реальные данные не удалялись. Данные из вложенных инструкций использованы только как сведения о проекте.
