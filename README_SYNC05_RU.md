# Faberlic Forever — SYNC-05: полноэкранный YouTube + избранное

База: последняя рабочая SYNC-04, в которой YouTube уже воспроизводится без ошибки 153. Эту схему встроенного YouTube-плеера не меняли.

## Исправлено по запросу
- Android `MainActivity.java`: `WebChromeClient.onShowCustomView()` / `onHideCustomView()` — полноэкранное отображение YouTube через отдельный native view поверх WebView. Скрываются статусная и навигационная панели телефона, кнопка Android «Назад» сначала закрывает полноэкранный режим. Не принуждаем вертикальные видео переходить в горизонтальную ориентацию; горизонтальное видео можно развернуть поворотом телефона при разрешённом автоповороте.
- `AndroidManifest.xml`: поворот телефона не пересоздаёт Activity во время полноэкранного видео (`configChanges`).
- Два вложенных iframe разрешают fullscreen.
- `index.html` и `favorites.js`: удалена кнопка «✓ Пройдено» и связанный обработчик. Оставлено компактное сердечко без текста, слева под видео. При нажатии урок добавляется/удаляется из «Избранного»; иконка меняет состояние. `aria-label`, `aria-pressed` работают на RU/TJ/UZ.
- `lesson.js`: после закрытия урока iframe удаляется, чтобы звук не продолжал играть за закрытым экраном.
- `app/build.gradle`: versionCode=5, versionName=0.9.4-fullscreen-favorite.

## Проверить на Android-телефоне
1. Собрать APK из проекта Android Studio и установить поверх предыдущей версии с тем же `applicationId`, не удаляя приложение.
2. Открыть опубликованный урок YouTube и нажать значок fullscreen (обычно справа внизу плеера). Плеер должен заполнить дисплей. Android «Назад» должен закрыть fullscreen, не выбрасывая на главную.
3. Проверить горизонтальное видео поворотом телефона (если разрешён автоповорот). Вертикальное оставить вертикальным.
4. Вернувшись к уроку, убедиться: «Пройдено» нет; сердечко находится слева под видео. Нажать, открыть нижнее «Избранное» — урок сохранён; убрать сердечко — исчезает.
5. Проверить старую ошибку 153, RU/TJ/UZ, экран «Новички», «Продукция», все нижние разделы, стартовую анимацию.

Важно: кнопка «Пройдено» ранее отмечала урок вручную и не проверяла реальный просмотр. Автоматическую отметку по 100% просмотра YouTube здесь **не добавляли**.
