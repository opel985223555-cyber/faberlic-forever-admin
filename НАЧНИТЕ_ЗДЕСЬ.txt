Откройте папку «1_САЙТ_НА_ХОСТИНГ».
Загрузите ВСЁ ЕЁ СОДЕРЖИМОЕ в корень репозитория faberlic-forever-admin,
где сейчас лежит index.html, с заменой существующих файлов.

То есть index.html должен оказаться на прежнем месте, рядом с assets и config.
САМУ папку «1_САЙТ_НА_ХОСТИНГ» загружать как вложенную папку НЕ НУЖНО.
Папки 2_FIREBASE и 3_ANDROID_STUDIO на хостинг загружать не нужно.

После завершения публикации GitHub Pages откройте:
https://opel985223555-cyber.github.io/faberlic-forever-admin/
Нажмите Ctrl+F5. В категориях появятся кнопки «Скрыть», «Закрыть», «Открыть».
При проверке 24.10.2026 на вашем сайте была установлена CMS-11 без этих кнопок.

2. FIREBASE — ОБЯЗАТЕЛЬНАЯ СЕРВЕРНАЯ ЧАСТЬ

Папка «2_FIREBASE» содержит функцию cms11Catalog и правила Firestore.
Она устанавливается в Firebase, а НЕ на GitHub Pages.
Для Cloud Functions нужны Node.js 22, Firebase CLI и тариф Firebase Blaze.

Откройте терминал в папке «2_FIREBASE» и выполните сами:

cd functions
npm ci
cd ..
firebase login
firebase deploy --only functions:cms11 --project faberlic-forever
firebase deploy --only firestore:rules --project faberlic-forever

Эти команды публикуют серверную функцию и правила в вашем Firebase.
При подготовке комплекта они НЕ выполнялись. Не запускайте общий deploy всех
функций. Если у вас есть другие функции, сохраняйте их настройки/codebase.

Правила входят в комплект в файле 2_FIREBASE/firestore.rules. Их также можно
опубликовать вручную: Firebase Console → Firestore Database → Rules → Publish.
Одни правила без функции cms11Catalog не обеспечат работу сохранения категорий.
Ошибка «internal [0]» по скриншоту ещё не диагностирована окончательно:
замена сайта сама по себе не гарантирует её устранение. Если после настройки
функции ошибка останется, нужны журнал функции или подробности ошибки запроса.

3. ЧТО ДЕЛАТЬ С ANDROID

Папка «3_ANDROID_STUDIO» — полный исходный проект приложения.
Откройте ЕЁ в Android Studio, выполните Gradle Sync и соберите APK.
Затем установите обновлённое приложение на телефон с прежним ключом подписи.
Готового APK в этом комплекте НЕТ; сборка APK и проверка на устройстве
в этой сессии не выполнялись. Используйте вашу конфигурацию Gradle/Android Studio.
Обновление хостинга само по себе не обновляет установленное приложение.

КАК РАБОТАЮТ КНОПКИ

«Скрыть» — категория и её подразделы исчезают из приложения.
«Закрыть» — категория видна с надписью «Закрыто на техническое обслуживание»,
вход закрыт. Предусмотрены RU/TJ/UZ.
«Открыть» — снимает ограничение категории с учётом статуса родителя.
Видео сохраняются, отметки избранного не удаляются.
Смена статуса поступает в приложение по подписке Firebase при наличии интернета.
Закрывать категорию можно без выбора родителя: для главной категории оставляйте
«Главная категория». Нельзя выбрать категорию родителем самой себя.
