CMS-13 SPARK — БЕЗ CLOUD FUNCTIONS И БЕЗ ПЕРЕХОДА НА BLAZE

ВАЖНО: этот комплект заменяет предыдущие версии админки CMS-11/12.
На хостинге должны быть файлы именно из этого ZIP.

ШАГ 1 — FIREBASE
Откройте FIRESTORE_RULES_CMS13_SPARK.txt из архива.
Скопируйте ВЕСЬ его текст.
Firebase Console → Firestore Database → Rules:
замените ВЕСЬ старый текст правил новым и нажмите Publish.
Не добавляйте новые правила в конец старых — замените полностью.
Функцию cms11Catalog устанавливать не нужно. Тариф Spark оставьте прежним.

ШАГ 2 — САЙТ
Распакуйте ZIP. Загрузите всё его СОДЕРЖИМОЕ прямо в корень репозитория
faberlic-forever-admin с заменой файлов. index.html должен заменить старый
index.html, папки assets и config — объединиться с прежними с заменой файлов.
Не загружайте папку, в которую вы распаковали ZIP, как дополнительную вложенную папку.
После публикации GitHub Pages нажмите Ctrl+F5.

Теперь нажмите «Скрыть» у «Продажи». При первом изменении новая админка
автоматически подготовит служебный индекс по существующим видео.
Видео при этом не удаляются и не переписываются.
Если появится сообщение о конфликте — обновите страницу и повторите действие.

«Скрыть» — скрывает категорию; «Закрыть» — техническое обслуживание;
«Открыть» — снимает ограничение. Категории с видео и родительские категории
с подразделами удалить нельзя. Видео сохраняются.

Данная поставка обновляет только сайт и правила. Android-проект CMS-12,
который уже предоставлен, совместим с этими статусами. Пересобирать его
специально из-за перехода админки на Spark не требуется. Для новой надписи
в приложении нужна ранее подготовленная версия Android CMS-12, а не старый APK CMS-10.

Никаких команд в терминале, установки Cloud Functions или подключения оплаты
для этого варианта не требуется. При подготовке реальные данные Firebase,
GitHub и main не изменялись. Подробные проверки — в tests/ и README_CMS13_RU.md.
