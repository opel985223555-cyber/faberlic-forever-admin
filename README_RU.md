# Faberlic Forever — админ-панель CMS-08

**Предназначение:** готовое управление видеоуроками и категориями Faberlic Forever через GitHub Pages + Firebase Authentication/Firestore. Сайт не загружает видеофайлы: он хранит только YouTube ID, настройки уроков и структуру разделов. Обложки всегда берутся с YouTube.

## Работа в панели

- **Видеоуроки:** добавить YouTube-ссылку, название, описание, категорию / вложенную тему, RU/TJ/UZ, вертикальный/горизонтальный формат, опубликовать или оставить черновиком. При вставке ссылки показывается обложка YouTube. Для одного языка и раздела новые уроки автоматически добавляются в конец. Из списка их можно поднимать и опускать стрелками ↑/↓ или перетаскиванием. Числового поля порядка нет.
- **Категории:** изменять название и описание на RU/TJ/UZ, добавлять любые новые вложенные подразделы, настраивать порядок ↑/↓ и статус «Открыт», «Скоро» или «Скрыт». Если опубликованных уроков нет, Android показывает «Скоро» автоматически. Существующие ID разделов сохраняются. Для защиты связей с уроками перенос заполненной категории к другому родителю заблокирован. Чтобы перенести такую категорию, сначала перенести уроки в другой раздел. Переименование/статус при этом доступны.
- **Обучение по статусам:** существующие 3/6/9/12/15/19/23% — вложенные разделы категории «Обучение по статусам», редактируются через «Категории».
- **Обзор:** актуальное количество уроков/публикаций/черновиков после загрузки.
- **Эфиры, Материалы, вопросы:** не реализованы в админке — эти модули остаются отдельными будущими задачами, чтобы не затрагивать стабильные экраны и Firebase.

## Подключение в существующий GitHub-репозиторий

1. **Сделать резервную копию** файлов текущего репозитория `faberlic-forever-admin`, прежде чем заменять код.
2. Из архива `Faberlic_Forever_Admin_CMS08_GITHUB_FROM_V04_PATCH.zip` обновить файлы, **сохраняя относительные пути** (`index.html` в корне, JavaScript в `assets/js/...`). Никакой ZIP на сайт не выкладывать. Альтернатива — использовать `...CMS08_FULL.zip`, который содержит полный сайт.
3. **Не заменять** существующие настройки Firebase `config/firebase-config.js` и не переносить пароль на GitHub.
4. Firebase Console → Firestore Database → Rules: скопировать правила из файла `firestore.rules` **вручную** и нажать **Publish**. Одной загрузки правил в репозиторий недостаточно!
5. После появления обновления на GitHub Pages нажать Ctrl+F5 и авторизоваться в панели. Открыть «Категории» → **«Опубликовать структуру»** ровно один раз, если кнопка отображается. Это создаёт `/taxonomy/catalog` с исходными категориями и переводами, не меняя ID уже опубликованных уроков. Если кнопки нет, каталог уже опубликован.
6. Проверить: открывается урок «Реклама» из Firestore; создать тестовый **черновик**, редактировать его, переставить ↑/↓ два урока на одном языке, затем удалить тестовый черновик. Переименовать тестовый пустой подраздел, проверить с другого браузера. Не удалять реальные данные.
7. **Для новых редактируемых категорий в Android** нужен клиент CMS-07 с чтением `/taxonomy/catalog` (в версии `Faberlic_Forever_CMS07_HEART_TOP_RIGHT_AndroidStudio.zip` это предусмотрено). Обновление одной веб-панели не обновляет старый установленный APK.

## Firebase и права доступа

- Проект: `faberlic-forever`, Firestore `(default)` в `europe-west3`.
- Firebase Authentication: Email/Password, административная учётная запись.
- В Firestore `/admins/{UID}` требуется поле `active` boolean `true`. Только подтверждённый администратор может записывать уроки и структуру категорий.
- Уроки хранятся в `/lessons/{id}`, структура — в `/taxonomy/catalog`.
- Неавторизованное приложение может читать **только опубликованные** уроки (запрос должен фильтровать `status == 'published'`) и общий каталог. Черновики нельзя читать без прав администратора.
- Обложки YouTube загружаются по ссылке, изображений в Firestore и APK нет. Загружать свои изображения нельзя.

## Границы выполненных тестов

Автоматизированный прогон интерфейса CMS-08 в Chromium с локальной имитацией Firestore: публикация исходной структуры, редактирование статуса и перевода, создание подраздела, защита переноса занятой категории, добавление урока, автопорядок, перестановка, редактирование урока в скрытой категории, мобильное меню. Проверки JS-синтаксиса и контроль неизменности утверждённых файлов. **Не проверено** реальное сохранение в вашем Firebase/публикация GitHub Pages после установки; они требуют ручной проверки с вашим входом. **Android APK** в этот архив не входит.
