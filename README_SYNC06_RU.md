# Админ-панель Faberlic Forever — YouTube-обложки v05

Это полный готовый для GitHub Pages набор файлов, основанный на опубликованной v04. Изменены ТОЛЬКО:
- `index.html` — превью под ссылкой YouTube;
- `assets/js/modules/videos.js` — автоматическое обновление превью и hqdefault для списка уроков;

Вопросы под уроком пока не реализованы; рекомендуется отдельная защищённая коллекция Firestore и модерация администратором.
