# Faberlic Forever · SYNC-06 · Автоматические обложки YouTube

Основа: рабочий Android-проект SYNC-05 с полноэкранным плеером и сердечком «Избранное».

## Изменения
- `modules/youtube-covers.js` — новый изолированный модуль обложек по валидному YouTube ID.
- `modules/home.js` — картинка на баннере и карточках «Новинки», без смены геометрии и кликов.
- `modules/categories.js` — миниатюры видео в списках внутри категорий.
- `modules/favorites.js` — миниатюры в «Избранном» без изменения хранения избранного.
- `modules/firebase-lessons.js` — миниатюра в существующей карточке «Продолжить просмотр».
- `styles.css` — только дополнительные правила обложек с fallback на старые градиенты.
- `index.html` — загрузка изолированного модуля до других модулей.
- `app/build.gradle` — versionCode 6, versionName 0.9.5-youtube-covers.

Обложки запрашиваются по HTTPS с i.ytimg.com. Файлы JPEG не записываются в Firestore, в APK или на Firebase Storage. На телефоне WebView может держать обычный временный кэш изображения. Если обложка отсутствует или сеть недоступна, остаётся прежний графический фон.

Продолжительность видео по YouTube ID автоматически не определяется без API или метаданных; пустая продолжительность теперь не показывает пустой бейдж. Данные уроков, их статус и фильтр языков не менялись.

## Админ-панель
Отдельный архив `Faberlic_Forever_Admin_YOUTUBE_COVERS_PREVIEW_v05.zip`: при вводе ссылки показывает ту же обложку для сверки. Сохранять новые поля не требуется. Обновление админки на GitHub Pages требует загрузить изменённые файлы сайта; локальный архив сам по себе опубликованный сайт не меняет.

## Вопросы под видео
ЕЩЁ НЕ ВНЕДРЕНЫ. Предлагаемый будущий модуль Firestore `lessonQuestions` со строгими правилами: пользователь может добавлять свой вопрос только после авторизации, администратор видит вопросы/отвечает/публикует, остальные видят только одобренные вопросы и ответы. Никогда не открывать Firestore на неограниченную запись для анонимного интернета.

## Проверка
Запустить `python tests/check_locked_files.py --allow ...` с перечисленными изменёнными модулями. Открыть проект в Android Studio, Build APK и тестировать на устройстве: Новинки, категория Новичку, Избранное, баннер, воспроизведение/fullscreen, переключение RU/TJ/UZ.
