# Faberlic Forever: проверка Firebase SYNC-02

## Что исправлено

- Отображение причины отсутствия видео в блоке «Новинки» (ошибка permission-denied, отсутствие сети, ожидание сервера).
- Кнопка «Повторить» появляется, только если запрос к Firestore не прошёл.
- Пустой локальный кэш Firebase не считается окончательным ответом сервера.
- В Android Logcat тег `FFPublishedLessons`, сборка `SYNC-02`.
- `versionCode 2` и `versionName 0.9.1-sync02` позволяют отличить установленную сборку от старой.
- Все зафиксированные разделы, splash, оформление и навигация не изменены.

## Важно

Эта сборка не подтверждает, что сервер Firebase отвечает с телефона. Для настоящей проверки надо пересобрать и установить именно этот проект.

1. Открыть проект через Android Studio (папка с `settings.gradle`).
2. Собрать APK: Build → Build APK(s).
3. Установить APK на телефон поверх старого приложения; при конфликте подписей не удалять данные без резервной копии.
4. При русском языке в «Новинках» либо появится «Реклама», либо понятный текст ошибки и кнопка «Повторить».
5. Если после установки отсутствует даже метка SYNC-02 в состоянии загрузки, запущена другая версия приложения. Проверить установленную версию в настройках Android.
6. Если ошибка сохраняется, прислать скриншот текста и, если возможно, Logcat по тегу `FFPublishedLessons`.

Нет необходимости менять админ-панель, опубликовывать урок заново или менять правила Firestore до получения кода ошибки. Внимание: это ZIP исходного проекта, не APK.
