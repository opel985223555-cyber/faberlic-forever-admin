Удаление учётной записи Faberlic Forever

Владелец приложения: Алишер Хафизов. Эта страница позволяет запросить удаление без доступа к приложению.

  1. В приложении откройте «О приложении» → «Удалить учётную запись и локальные данные». Эта кнопка также доступна на экране активации. Подтвердите удаление при подключённом интернете.
  2. Если приложение недоступно, отправьте запрос на 000040000@list.ru с темой «Удаление учётной записи Faberlic Forever». Укажите ID установки из экрана «О приложении» или экрана активации. Если ID недоступен, укажите ранее выданный код и платформу Android/iOS: владелец уточнит данные для поиска и подтверждения принадлежности записи. Не отправляйте пароли.

Удаляются анонимная учётная запись Firebase Authentication, запись доступа установки и её связь с одноразовым кодом. При удалении внутри приложения также очищаются локальная история и избранное. Удаление через email не очищает данные на недоступном устройстве: очистите данные приложения или удалите приложение самостоятельно.

Использованный код остаётся отмеченным как использованный, без ID удалённой учётной записи. Он не становится доступным повторно. Общие учебные видео и материалы не являются личными данными установки и сохраняются. Для нового доступа потребуется новый код.

Запрос через email обрабатывается владельцем вручную после подтверждения принадлежности записи; ответ и срок исполнения сообщаются по email.
