## Целостность и источники

База админки: GitHub main `bb02923f0f6af674eae5aae78a06b8c59e09181a`, повторная read-only проверка 25.10.2026 подтвердила тот же commit. Модуль категорий, CSS подсветки и category-availability сохранены из этой версии; исправление sameValue осталось. Старый ZIP CMS-10 не заменял более свежие функции.

Android/iOS исходники взяты из приложенных архивов. Исходные каталоги player/, splash/, fonts/assets и базовые styles.css сохранены побайтно; modules/lesson.js получил только проверку доступа/историю, а исходный способ встраивания плеера своей платформы сохранён.

Тесты включены в verification/ каждого проекта с инструкциями. Тесты правил аварийно отказываются работать без localhost FIRESTORE_EMULATOR_HOST. В тестах нет запросов на запись в production. 5000 кодов генерировались только в памяти поддельного SDK; локальный Rules-тест отдельно проверил реальный пакет 200 кодов. В рабочей Firebase нет созданных агентом кодов/аккаунтов/удалений. GitHub/Firebase не публиковались, main не менялась.

## Ограничения перед выпуском

Нет macOS/Xcode и физических устройств. Native iOS НЕ СОБРАН; Swift-парсер не доказывает совместимость Firebase SDK. Реального GoogleService-Info.plist в исходном iOS архиве не было: владелец должен добавить конфигурацию зарегистрированного iOS-приложения. Android собран, но native Firebase Authentication, WebView, YouTube, клавиатура и account deletion на устройстве ещё требуют приёмки.

Проверка магазинами не проводилась и одобрение не обещается. Нужны App Privacy/Data Safety, рабочий код для ревью, актуальная политика и опубликованная внешняя страница удаления аккаунта. Требования проверены по [Apple Guidelines](https://developer.apple.com/app-store/review/guidelines/), [Apple account deletion](https://developer.apple.com/support/offering-account-deletion-in-your-app/), [Google account deletion](https://support.google.com/googleplay/android-developer/answer/13327111?hl=en). Публикация и реальные 5000 кодов остаются отдельными действиями владельца.
