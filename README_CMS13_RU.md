# CMS-13 Spark

Это версия админки CMS-12 с прежними кнопками доступа, но без Firebase Cloud Functions. Убраны импорт SDK Functions и httpsCallable. Запись идёт через транзакции Firestore Web SDK; Firebase Spark поддерживает этот клиентский путь. Правила и сайт требуется обновить согласованно. Публикаций из этой сессии не выполнялось.

## Индекс и конкурентные изменения

Первое изменение каталога или урока под активной учётной записью администратора создаёт/обновляет taxonomy/catalog до protocol=13 и catalogGuards/membership. Подготовка читает версию общей блокировки ПЕРЕД серверным запросом всех lessons и повторно проверяет её в транзакции вместе с версией каталога. Новые правила требуют протокол счётчиков при создании, переносе и удалении видео, поэтому старый клиент не может незаметно добавить видео между проверкой пустоты и удалением категории. До завершения первой индексации такие изменения блокируются.

Начальная инвентаризация выполняется доверенной админкой под действующей ролью admins/{uid}. Она проверяет все языки, статусы и старые categoryId/topicId привязки; существующие документы уроков не изменяются. Счётчик counts хранит число всех уроков конечной категории (не только опубликованных). После инициализации повторный bootstrap счётчиков правилами запрещён. Последующие изменения счётчиков проверяются через существование/состояние конкретного документа урока до и после той же транзакции; отдельное обнуление счётчика запрещено. Индекс нельзя удалять или переинициализировать новой админкой.

Уменьшение каталога разрешено только как удаление одной конкретной категории: все остальные элементы должны быть сохранены, счётчик видео должен равняться нулю, дочерних категорий быть не должно. Добавление одной категории, изменение одного элемента и перестановка двух соседних элементов проверяются как отдельные операции. Поэтому старая лазейка «удалить ID и одновременно добавить другой, сохранив длину массива» не используется. Между порядковыми значениями после удаления могут оставаться промежутки — визуальный порядок сохраняется, номера пользователю не показываются.

Полная проверка дерева, наследования и соответствия корневых привязок уроков выполняется кодом админки на свежей инвентаризации с общей блокировкой. Правила защищают роль, версии, счётчики и конкретные операции; первичный импорт индекса и построение структурных метаданных доверены авторизованному администратору. Прямое ручное изменение служебных метаданных через привилегированную консоль/серверные импорты не относится к поддерживаемому пути: Admin SDK/консоль обходят правила Firebase. Если другие приложения тоже записывают lessons, им нужен новый протокол; старые писатели будут получать отказ. Предоставленный Android-клиент читает данные, поэтому его подписки остаются совместимыми.

При переносе заполненного поддерева, повреждённой структуре, несовпадении индекса с коллекцией или конфликте редакций операция останавливается. Инициализация индекса сама по себе может завершиться до последующего отклонённого действия; она не удаляет уроки или категории. При конфликте нужно обновить страницу. Старые открытые вкладки CMS-10/11/12 после установки правил необходимо закрыть или перезагрузить.

## Сохранённые функции

Кнопки «Скрыть», «Закрыть», «Открыть» и режимы active/hidden/soon + closureReason=maintenance сохраняются из CMS-12; описание не заменяется служебной надписью. Все переводы RU/TJ/UZ сохранены. Админская авторизация не менялась. Исходные модули videos.js, live.js и materials.js, shell.js, state.js и стили относительно CMS-12 сохранены. Общий Firebase/repository слой меняется для индекса, транзакций и удаления. Публичное чтение каталога и опубликованных уроков остаётся разрешённым. Статусы интерфейса приложения не заменяют правил приватности прямого чтения опубликованного видео.

## Проверки

40/40 браузерных проверок полного интерфейса с локально подменённым SDK; отдельно проверено отсутствие импорта Firebase Functions. 17/17 групп тестов настоящего Web SDK на локальном Firestore emulator: первичная индексация старых данных, CRUD категорий, доступность, все языки/статусы, legacy topic, глубина 20, изменения видео, конфликты, запрет подмены ID и счётчиков, прямой запрет удаления занятой категории, 8 гонок создания с удалением и гонка переноса с удалением. Отказы в негативных тестах ожидаемы. Исторические тесты прежних протоколов в этот ZIP не включены.

Также пройдены tests/test_content_cms10.cjs, tests/test_youtube_only_policy.py, контроль замороженных файлов (с разрешёнными изменениями) и node --check всех выдаваемых JS/CJS. Настоящий Firebase, облачная публикация и Android-устройство не использовались. Новый APK не требуется для замены серверного пути админки. Ранее выданный Android CMS-12 совместим.

Для повторения тестов установите зависимости в отдельную локальную папку, задайте NODE_PATH на её node_modules. Нужны playwright + Edge для браузера; firebase, firebase-admin, @firebase/rules-unit-testing, firebase-tools и совместимая Java для эмулятора:

 node tests/test_cms13_browser.cjs
 firebase emulators:exec --config firebase.emulator.json --only firestore --project demo-ff-cms13 "node tests/test_cms13_emulator.cjs"
 node tests/test_content_cms10.cjs
 python tests/test_youtube_only_policy.py

Локальный прогон: Node.js 24, Firebase CLI 13.35.1, Firestore emulator 1.19.8. Продакшен не проверялся. Лимиты бесплатного Spark продолжают действовать; изменение каталога читает коллекцию lessons для проверки целостности. При отказе чтения/превышении квоты удаление не выполняется. Cloud Functions и Blaze для этой реализации не нужны.
