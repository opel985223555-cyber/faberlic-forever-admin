# Faberlic Forever — тест подключения видеоуроков Firebase

## Что изменено

- Firestore `lessons`, только `status == published`, в реальном времени.
- Чтение через нативный Firebase Firestore Android SDK и отдельный JS-адаптер WebView.
- Внешняя админ-панель без изменений; Android-клиент не требует логина администратора.
- Уроки отображаются в выбранном языке RU/TJ/UZ и открываются в уже утверждённом видеоплеере.
- Категории social/ranks привязаны к `groupId`/`topicId`.
- Шесть тестовых карточек и три тестовых баннера заменяются живыми записями, когда веб-страница запускается из Android.
- Локальные интерфейсы / анимация / стили не менялись.

## Ограничения

- Это исходный Android-проект для сборки. APK здесь не собран.
- Обложки YouTube, ссылки и воспроизведение в реальном WebView нужно проверить на телефоне с интернетом.
- При первом запуске с интернетом нужна удачная загрузка Firestore; последующие снимки могут быть доступны из кэша Android Firebase.
- При отсутствии опубликованных уроков на выбранном языке экран «Новинки» будет пуст.
- Демо-данные браузерного HTML-просмотра не отображаются в установленном Android-приложении.
- Изменение порядка уроков drag-and-drop в админ-панели ещё НЕ выполнено; это отдельная работа.
- Firestore правила нужны уже установленные в Firebase: `lessons` reading by published status and no anonymous write.

## Проверка

1. Открой проект в Android Studio, Gradle Sync, Build > Build APK(s).
2. Установи на Android. После запуска короткой 6,3-сек. заставки выбери RU.
3. Категория «Новичку» → должен показываться урок «Реклама» (status=published, categoryId=newbie, language=ru).
4. Открой его и проверь YouTube плеер на реальном телефоне.
5. В админ-панели переключи урок в черновик — он должен пропасть из Android после обновления Firestore.
6. Проверь TJ/UZ, переходы, избранное, поиск, навигацию, повторный запуск.
7. При проблеме смотри Android Studio Logcat по тегу `FFPublishedLessons`.
