# Faberlic Forever — админ-панель CMS-07 / YouTube-only

Основа: v05. Подтверждённый Firebase Auth, оформление, главные разделы сохранены.

## Изменения

1. «Порядок показа» УДАЛЁН из формы урока. При создании видео автоматически добавляется в конец выбранного раздела и языка. В списке видео ↑/↓ или перетаскивание меняют порядок и записывают новые номера в Firestore одним атомарным batch.
2. Категории в меню «Категории» можно редактировать и добавлять; вложенность произвольная (практический максимум 20 уровней). RU/TJ/UZ названия и описания, порядок ↑/↓ и статусы «Открыт», «Скоро» и «Скрыт». Идентификаторы существующих разделов НЕ меняются. При первом запуске нажмите «Опубликовать структуру», чтобы перенести утверждённые названия и подразделы в Firestore.
3. Для всех видео, карточек, «Новинок», «Избранного» и главного баннера используется только автоматическая обложка YouTube. Собственные изображения не загружаются; место в Firestore и APK под них не расходуется.
4. Ранее сохранённые `coverData`/`bannerCoverData` при чтении игнорируются: изображение всегда берётся с YouTube.
5. Данные видео остаются в `/lessons`, категории в `/taxonomy/catalog`. Удаления опубликованных уроков и изменения старых ID нет.

## ОБЯЗАТЕЛЬНЫЙ ПОРЯДОК ОБНОВЛЕНИЯ

1. В Firebase Console → Firestore Database → Rules вручную опубликовать новые правила из `firestore.rules`. **Файл в GitHub сам правила Firestore не меняет!** Новое правило позволяет публично читать документ `/taxonomy/catalog`, а записывать только авторизованному админу.
2. На GitHub `faberlic-forever-admin` обновить файлы из архива, сохранив ту же структуру папок. НЕ загружать ZIP как файл. Не удалять существующий `config/firebase-config.js`. Пакет `*_ADMIN_GITHUB_PATCH.zip` содержит только изменённые файлы для замены.
3. Дождаться публикации GitHub Pages, обновить страницу Ctrl+F5, войти и открыть «Категории» → «Опубликовать структуру». Это создаст каталог с оригинальными 9 разделами и 12 вложенными темами, включая сохранённые переводы на RU/TJ/UZ.
4. Только после этого собрать Android-проект CMS-07-YT и установить APK поверх предыдущего.

## Функции администратора

- Для редактирования каталога нажать «Категории» → «Изменить». Статус «Скоро» закроет вход в раздел в приложении, «Скрыт» уберёт его из списка. Разделы без опубликованных уроков получают «Скоро» автоматически.
- Для подкатегории нажать «Новый», выбрать «Родительский раздел» и заполнить название RU. Можно заполнить TJ и UZ (иначе будет использовано название RU).
- Сначала выбрать нужный раздел в форме видео, затем вставить YouTube ссылку. Обложка берётся автоматически. Порядок определяется автоматически. В списке видео ↑/↓ меняет местами уроки только внутри ОДНОГО раздела и языка.
- Обложки используются исключительно с YouTube. Загружать собственные фотографии в админ-панели нельзя.

## Условия и ограничения

- Без публикации новых Firestore Rules раздел «Категории» не сможет записываться в Firestore. Видеоуроки при этом продолжают работать.
- Тест браузера не равен проверке готового Android APK. После установки проверить все переходы, баннер, картинки, язык, Firebase и YouTube full screen на реальном телефоне.
- Версия не включает форум вопросов под уроком (отдельный модуль).
- Независимое управление слайдами и сортировкой баннеров пока не добавлено: по-прежнему используются первые три опубликованных урока выбранного языка, их обложки для баннера тоже берутся с YouTube.
