# Faberlic Forever — Android CMS-07

Основа SYNC-06 с ранее зафиксированными исправлениями YouTube 153, полноэкранного режима и сердечка избранного. Утверждённые стили, splash, плеер, пять нижних вкладок не переделаны.

- WebView получает документ `/taxonomy/catalog` через `PublishedLessonsBridge`, независимый listener. Старые категории и подкатегории используются как fallback до подключения/первой публикации каталога.
- Экран категорий отображает уровни вложенности, RU/TJ/UZ подписи, статус «Скоро» и отключает пустые/закрытые категории. «Назад» проходит вверх по дереву разделов; на главную не выбрасывает.
- Уроки старого формата с `categoryId+topicId` совместимы. Новые видео используют `leafCategoryId` для более глубокой вложенности.
- Обложки карточек, «Новинок», избранного и главного баннера берутся только с YouTube по `youtubeId`. Свои фотографии не используются; никаких изображений в APK не добавлено.
- Порядок карточек внутри категорий берётся из Firestore `order`; администратор меняет этот номер через ↑/↓, приложение ничего не пишет.

Важно: без публикации новой версии Firebase Security Rules и каталога из админ-панели Android продолжит работать со старой встроенной структурой. Синхронизация реального Android-устройства и сборка APK здесь не подтверждены; прогон проведён в Chromium WebView-подобном тестовом стенде, не на Android.


## Обложки (CMS-07-YT)
Все карточки уроков, «Новинки», избранное и баннер используют только автоматические заставки YouTube по `youtubeId`. Пользовательские фото не принимаются. При недоступности изображения используется прежний графический фон.
