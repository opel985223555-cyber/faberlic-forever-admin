# Faberlic Forever SYNC-03: изолированное исправление категорий

## Причина
В `modules/categories.js` команда `openCategory` отправляла пользователя на Главную через `go('home')`. В результате нажатие «Новичку», «Продукция» и других обычных категорий переключало нижнюю вкладку на «Главная».

## Изменения
- Только `modules/categories.js`: обычные категории открываются в текущем экране «Категории», показывают опубликованные уроки своего направления и языка или сообщение об отсутствии уроков; кнопка «К категориям» возвращает назад.
- Изменён только `versionCode` 2→3 и `versionName` 0.9.2-sync03-categories для распознавания сборки Android.
- Обновлён контрольный список SHA-256 для намеренно изменённых файлов.
- `core/navigation.js`, `modules/firebase-lessons.js`, Android Firestore bridge, остальные модули, заставка, шрифт и дизайн не изменены.

## Проверка на телефоне
1. Собрать новый APK из этого проекта в Android Studio (Build > Build APK(s)) и установить поверх ранее установленного; не удалять приложение с данными.
2. Нажать «Категории» → «Новичку»: остаётся вкладка «Категории», виден список, если опубликован урок «Реклама».
3. Нажать «К категориям», затем «Продукция»: остаётся вкладка «Категории», появляется список уроков либо сообщение об отсутствии.
4. Проверить «Соцсети и продвижение» и «Обучение по статусам», навигацию назад, языки RU/TJ/UZ и кнопки нижнего меню.
5. Если «Реклама» отсутствует, смотреть диагностику Firebase в «Новинках»: проблема синхронизации остаётся отдельной задачей и не связана с переходами категорий.

ZIP содержит исходники Android Studio, не APK.

## Автоматические регрессионные проверки
В `tests/test_category_navigation.py` проверяются все семь обычных категорий, обучение по статусам, соцсети, все пять нижних кнопок, RU/TJ, открытие урока, программная кнопка Android «Назад» и отсутствие ошибок JavaScript. В тесте используется локальная имитация ответа Firebase, не реальное интернет-подключение. Запуск в окружении Python с `playwright` и Chromium: `python tests/test_category_navigation.py`.
